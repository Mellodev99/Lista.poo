## Objetivo da lista

A lista tem como objetivo desenvolver e praticar os conhecimentos básicos de programação em Python, estimulando a construção de algoritmos, a resolução de problemas e a utilização de diferentes estruturas e recursos da linguagem.

Além disso, a atividade busca desenvolver a capacidade de interpretar problemas e transformá-los em soluções computacionais.

## Conteúdos trabalhados

Durante a resolução das questões, foram trabalhados os seguintes conteúdos:

* Variáveis e tipos de dados;
* Entrada e saída de dados (`input()` e `print()`);
* Operadores matemáticos e lógicos;
* Estruturas condicionais (`if`, `elif` e `else`);
* Estruturas de repetição (`for` e `while`);
* Listas;
* Dicionários;
* Funções;
* Parâmetros e retorno de funções;
* Tratamento de exceções com `try` e `except`;
* Manipulação de strings;
* Operações matemáticas;
* Organização e armazenamento de dados;
* Programação Orientada a Objetos.

## Organização das questões

## Orientações para execução dos códigos

Para executar os códigos, é necessário ter o **Python 3** instalado no computador.

Após clonar ou baixar o repositório, abra o terminal na pasta onde estão os arquivos.

Para executar uma questão específica, utilize:

```bash
python nome_do_arquivo.py
```

Por exemplo:

```bash
python 01.py
```

Em alguns sistemas, pode ser necessário utilizar:

```bash
python3 01.py
```

Os exercícios que solicitam informações ao usuário devem ser executados pelo terminal, pois utilizam comandos como `input()` para receber os dados.

### Requisitos

* Python 3.x instalado;
* Editor de código ou IDE, como Visual Studio Code;
* Terminal para execução dos programas.

### Observação

Cada exercício possui sua própria lógica e pode solicitar diferentes informações ao usuário. Portanto, leia as instruções apresentadas pelo programa durante sua execução e forneça os dados solicitados.
